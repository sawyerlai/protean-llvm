--- Implementation Notes ---
Key insight: ForwardAnalysis::dataUsesPublic() returns false for mayLoad()
instructions, so load DEFs never become public through forward() alone.
The fix seeds load DEFs as public explicitly during COPY replacement
when the load's base/index address is the declassified register.
The backward walk with copy chain following seeds defining instruction
DEFs so forward() propagates publicness through arithmetic chains.

--- Known Overhead ---
preserve_allcc calling convention adds COPY instructions (push/pop, mov
register shuffles) for the annotation calls. For int32_minmax, the
annotated version has 0 PROT but more instruction bytes (49 vs 44).
However, PROT prefixes are the critical overhead in Protean's threat model.
